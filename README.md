# 李世怡 · 华润江中营销管培生作品集

应聘华润江中制药集团有限责任公司 · 营销管培生。

公开网站：https://lishiyi-aia.github.io/huarun-jiangzhong-marketing-trainee/

独立复制自 https://lishiyi-aia.github.io/market-trainee-finetoday/ ，保留原站的3D场景、版式、图片与交互。原站源文件与发布版本不作修改。

## 三个项目

1. **AI资讯产品营销推广与转化优化**：需求与价格反馈 → 推广方案 → 品牌内容、达人、线上线下活动 → A/B测试与AI看板 → 渠道预算及下一轮传播调整。
2. **AI教育产品客户沟通与推广落地**：市场研究与反馈归类 → 宣传内容与材料 → 客户对接及跨团队准备 → 宣讲体验与渠道合作 → 10条改进建议及后续跟进。
3. **ZUS Coffee新品上市与终端传播**：消费者与竞品信息 → 新品卖点及宣传主题 → Instagram内容 → 线上首发与FamilyMart门店物料/排期 → 每周监测及下一轮调整。

履历内容以用户2026年10月15日4:18提供的最新简历截图为准，统一维护在 `web/src/data/resumeSnapshot.json`。卡片简介保持精简，完整项目展示调研输入、本人工作、执行材料、结果及复盘去向；工具演示与历史结果分别标注。

`web/` 为网站源文件，`docs/` 为 GitHub Pages 发布目录。

## 本地构建

在 `web/` 中执行 `npm install`、`npm run build`。构建生成的 `web/dist/` 复制到 `docs/`，GitHub Pages 从 `main` 分支的 `/docs` 发布。
